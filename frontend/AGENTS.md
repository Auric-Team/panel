# Frontend Engineering Directives

- **Framework**: Next.js 14+ (App Router), React 18+, TypeScript, TailwindCSS, Lucide Icons.
- **Components**: Server Components by default; `'use client'` only where state or browser APIs are required.
- **Design & UI**: High visual polish, subtle depth, responsive layout across all breakpoints, smooth micro-interactions.
- **States**: Provide skeleton loaders for async states, accessible empty states, and user-friendly error boundaries.
- **Integration**: Strict TypeScript synchronization with backend API response schemas and token handling.
